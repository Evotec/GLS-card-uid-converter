# GLS Card UID Converter

Et lille offline web-værktøj til at konvertere mellem UID i HEX/decimal og byte-vendt UID.

## Brug

Åbn `index.html` i en browser.

Eksempel:

```text
UID fra NFC-app:      DAB55246
Byte-vendt UID HEX:   4652B5DA
Byte-vendt decimal:   1179825626
```

Værktøjet kræver ikke internet og bruger kun lokal JavaScript i browseren.
